# Changelog

All notable changes to `@bladepdf/node` are documented here. This project
follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-28

- Initial server-side Node.js and TypeScript SDK.
- Added HTML and cloud-template rendering with buffered, streamed, file, and
  background delivery.
- Added the secure framework-agnostic local asset pipeline.
- Added webhook signature verification.
